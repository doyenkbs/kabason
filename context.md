# Context — kabason.com

Kabason Mail, a small private mail service: a home page and a mail help page for members
with @kabason.com mailboxes (in practice family and friends, presented in a business tone). Static, on Cloudflare Pages, publishing `public/` only.

Mail runs on a separate self-hosted server (Stalwart mail server, Bulwark webmail at
webmail.kabason.com) with Authentik SSO. This site only links to it.

The earlier tools site that lived here moved to itkab.com. Its files are in git history and
in `../kabason.com-archived`.
